# 📌 Project: Gen Z – Career Aspirations (Excel Dashboard)
Tools Used: Excel, Pivot Tables, Charts, Conditional Formatting, Data Cleaning

🚀 Description:
Designed an interactive Excel dashboard to explore the career goals, interests, and expectations of Gen Z students 👩‍🎓👨‍🎓. Collected and cleaned real-time data, then used visual storytelling to highlight trends in career choices, preferred industries, and influencing factors like technology, work culture, and salary 💼📊.

🔍 Key Insights Delivered:

Top career choices among Gen Z (e.g., tech, entrepreneurship, design) 🌐

Gender-wise & city-wise trends in aspirations 📍

Key factors driving career decisions (job security, passion, salary) 💡

Visual dashboard for easy interpretation and decision-making 🎯

💥 Impact: Helped educators, mentors, and career planners better understand and guide Gen Z based on real preferences and data-driven insights.
